Musical Lick Modifier

Max Su
Advisor: Scott Petersen

Abstract

This project proposes a rule-based system for modifying improvisational licks through MIDI. Targeted toward aspiring jazz musicians, the tool enables users to explore melodic regeneration and embellishment techniques without relying on large datasets or more self-learning models. By using Markov chains, the program can analyze both pitch class and rhythmic transitions within a given lick and will generate new variations that preserve its rhythmic and harmonic structure. The structure of the system is in three parts: the parser builds bar-specific transition matrices, while the creator samples pitches and rhythms from these matrices. Finally, the embellisher further refines the output by inserting idiomatic jazz gestures such as triplet turn motions. This project also emphasizes ease of use, allowing musicians access to a fast tool for quick inspiration. The goal is to require as little input from the user as possible — no large training sets or data preparation — just a simple one-track MIDI file and chord progression. Users input a MIDI file and corresponding chord progression, and the program quickly outputs a modified lick, instantly opening the music in MuseScore. The model is designed to be educational rather than generative at scale — it is most effective when aiding musicians in creative ruts, providing new perspectives on how melodic lines can be constructed against a harmonic structure. By prioritizing transparency and stylistic adherence to bebop conventions, this project serves as a bridge between computational modeling and jazz pedagogy. Ultimately, it demonstrates how symbolic rule-based approaches can foster growth and enhance improvisational fluency in improvisational musicians.
